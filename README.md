# DaoCrust

DaoCrust implements a distributed, fault-tolerant ledger system, integrating blockchain technology for scalable infrastructure and robust framework development.

With DaoCrust, you get a lightweight tool that stays out of your way.

**What you get**

- DaoCrust implements a distributed, fault-tolerant
- ledger system, integrating blockchain technology
- for scalable infrastructure and robust

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoCrust.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DaoCrust is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
